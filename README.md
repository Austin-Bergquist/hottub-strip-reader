# Hot Tub Strip Reader

Read hot tub test strips by tapping swatches or a photo, and get a dose plan scaled to your tub's gallons.

- Built-in key for the EasyTest 7-way strip
- **New from bottle**: photograph any brand's color chart, tap its swatches, and save it as a key
- Keys, tub size and sanitizer choice are saved in your browser

Live: https://austin-bergquist.github.io/hottub-strip-reader/

Version history is kept at the top of `index.html`.
